پنل موبایلی مدیریت سفارش‌های بله

این نسخه برای مدیریت سفارش‌ها ساخته شده و خودش کاربرانی را بدون رضایتشان
به کانال اضافه نمی‌کند. برای استفاده واقعی باید منبع جذب عضو داوطلبانه
(مثلاً لینک دعوت) را به آن متصل کنید.

اجرای محلی:
1) Python 3.10+ نصب کنید.
2) در این پوشه:
python -m venv .venv
Windows: .venv\Scripts\activate
Linux/macOS: source .venv/bin/activate
3) pip install -r requirements.txt
4) python app.py
5) با گوشی در همان شبکه محلی می‌توانید با آدرس IP کامپیوتر و پورت 5000 وارد شوید:
http://IP-COMPUTER:5000

برای استفاده فقط با گوشی و بدون کامپیوتر، مرحله بعد استقرار همین پروژه روی یک
میزبان وب است.
